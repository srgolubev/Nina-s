## 1. О проекте

**TranquilHaven Coaching** — частная психологически-информированная коучинговая
практика для женщин. Сайт-визитка: рассказывает о практике, формирует доверие
и ведёт к одному целевому действию — **бронированию бесплатного discovery-звонка**.

| Параметр | Значение |
|---|---|
| Название | TranquilHaven Coaching |
| Слоган | *Less noise. More you.* |
| Доп. посылы | *Your Tranquil Haven* · *Private · Thoughtful · Low-Noise* |
| Аудитория | Женщины: эмоциональная ясность, отношения, жизненные переходы |
| Регалии | ICF Member · ICF-Trained Coach (Level 2) · 1500+ часов обучения психологии |
| Формат | Онлайн (Zoom или audio-only), 50 минут |
| Цена | $100 за сессию |
| Язык сайта | **Только английский** (решение согласовано) |
| Тон | Уют, доверие, лёгкость, тишина — никакого «хайпа» и давления |

### Ключевое требование — комплаенс
В тексте многократно подчёркивается: **коучинг ≠ психотерапия / counseling /
mental health treatment**. Это не косметика, а юридическая необходимость (США).
Дисклеймеры должны быть видимыми на релевантных страницах и в футере.

## 2. Технологический стек

| Слой | Выбор | Почему |
|---|---|---|
| Фреймворк | **Astro** (статический сайт) | Быстрый, отличный SEO, ноль JS по умолчанию, простой контент-ориентированный сайт |
| Стили | CSS с дизайн-токенами (custom properties) | Без тяжёлых зависимостей; можно подключить Tailwind при желании |
| Контент | Astro Content Collections (Insights, Resources) | Статьи как Markdown-файлы — легко добавлять новые |
| Шрифты | `Fraunces` (заголовки, мягкий serif) + `Mulish` (текст, sans) | Спокойная, «тёплая» типографика |
| Бронирование | **Calendly** — встроенный inline-виджет | Стандарт для коучей |
| Форма контакта | Formspree (или Netlify Forms) | Статический сайт без бэкенда; письмо на почту коуча |
| Хостинг | Netlify / Vercel / Cloudflare Pages | Бесплатно, авто-деплой из ветки, HTTPS |

> Стек по тех-части не был выбран явно — взят Astro как рекомендация.
> Легко заменить на чистый HTML/CSS или Next.js, если потребуется.

## 3. Структура сайта

Решение заказчика: **полная версия — 9 разделов** из документа «Структура
сайта». Визуальный стиль — по макету клиента (см. §4).

```
/                 Home        — герой, 3 карточки, финальный CTA
/about            About       — о практике, философия
/coaching         Coaching    — услуга, формат, цена, дисклеймер
/credentials      Credentials — регалии, обучение
/insights         Insights    — список статей-размышлений
/insights/[slug]  Insights    — отдельная статья (×3 готовых)
/resources        Resources   — рефлексивные гайды (×3 готовых)
/testimonials     Testimonials— отзывы клиентов
/faq              FAQ         — большой раздел вопросов-ответов
/contact          Contact     — Calendly + контактная форма
/privacy          Privacy Policy (служебная, для комплаенса)
/404              Страница не найдена
```

Навигация: Home · About · Coaching · Credentials · Insights · Resources ·
Testimonials · FAQ · Contact. 9 пунктов — на десктопе уместить в один
аккуратный ряд; на мобильных «бургер»-меню. Чтобы разгрузить шапку, Insights
и Resources можно свести в выпадающее подменю «Insights & Resources».

> Примечание: на макете клиента в шапке 5 пунктов. Согласовано делать полную
> версию (9 разделов); пункт «Services» с макета соответствует «Coaching».

## 4. Дизайн-система

Макет клиента подтверждает направление: полноэкранное прибрежное фото в герое,
рукописный шрифт в логотипе и заголовках, тёплый песочный фон, кремовые
карточки, кнопки приглушённо-бирюзового цвета, футер с иконками соцсетей.

### Палитра (выведена из референсов и макета)

| Токен | Цвет | Применение |
|---|---|---|
| `--sand` | `#EFE3D2` | Основной фон (текстура песка) |
| `--cream` | `#FBF8F3` | Карточки, светлые блоки |
| `--sand-deep` | `#E0CDB4` | Разделители, второстепенный фон |
| `--sky` | `#BBD0DD` | Небо в герое, мягкие блоки |
| `--teal` | `#5C8795` | **Основные кнопки CTA**, ссылки |
| `--teal-dark` | `#436370` | Hover кнопок |
| `--blush` | `#E2B7A3` | Тёплый акцент (закат) |
| `--coral` | `#BE8A5E` | Вторичная акцент-кнопка («Read Reviews») |
| `--ink` | `#40453F` | Основной текст (тёплый графит) |

### Типографика

- **Логотип и заголовок героя** — рукописный шрифт (напр. `Pinyon Script` /
  `Parisienne`). Использовать дозированно — только в брендинге и герое.
- **Заголовки разделов** («About Me», «My Services») — элегантный serif
  (`Cormorant Garamond`), ради читаемости.
- **Основной текст** — чистый sans (`Mulish` / `Inter`).

### Композиция (по макету)

- Полноэкранный герой: фото маяка/заката (из Drive), скриптовый заголовок,
  подзаголовок, кнопка CTA по центру; полупрозрачный оверлей для контраста.
- Под героем — секция из **3 карточек**: About Me (круглое фото коуча),
  My Services, Client Testimonials — у каждой картинка, подпись и кнопка.
- Финальная CTA-секция «Ready to Find Your Haven?» на песочном фоне.
- Футер с иконками соцсетей (Facebook, Instagram, LinkedIn, Twitter).

### Принципы

- **Много воздуха**, низкая плотность, «low-noise».
- Мягкие скругления, деликатные тени, плавные градиенты заката.
- Тонкие декоративные разделители у заголовков (как на макете).
- Анимации минимальны: мягкое появление при скролле, `prefers-reduced-motion`.

Доступность: контраст AA (проверить текст поверх фото героя — нужен оверлей),
видимый фокус, семантические теги, alt-тексты.

## 5. Страницы — содержание

Весь текст уже готов в .docx, переносится почти дословно.

- **Home** — полноэкранный герой («Welcome to Tranquil Haven Coaching» +
  «Find Your Inner Peace and Balance» + кнопка «Start Your Journey»); секция
  из 3 карточек (About Me / My Services / Client Testimonials); финальная
  CTA-секция «Ready to Find Your Haven?» с кнопкой «Contact Me» (по макету).
- **About** — *Less noise. More you.*, описание практики, философия,
  дисклеймер «coaching only».
- **Coaching** — описание услуги, список тем (отношения, границы, переезд,
  идентичность…), формат (50 мин, Zoom/audio, EN/RU), цена $100, блок
  «Important Notice».
- **Credentials** — список регалий и обучения, дисклеймер.
- **Insights** — карточки 3 статей → отдельные страницы:
  *When clarity feels like silence* · *When relationships feel heavy* ·
  *Life transitions reshape identity*.
- **Resources** — 3 рефлексивных гайда: *5 Questions for Emotional Clarity* ·
  *A Gentle Boundary Check-In* · *When You Feel Stuck in a Life Transition*.
- **Testimonials** — короткие цитаты (A.M., S.K., M.R., Client USA) +
  примечание «results not guaranteed».
- **FAQ** — аккордеон по всем вопросам из документа (что такое коучинг, стиль,
  не терапия, конфиденциальность, цена, отмена и т.д.).
- **Contact** — встроенный Calendly + контактная форма (имя, email, телефон
  опц., сообщение) + примечание о приватности.
- **Privacy Policy** — на основе абзацев о сборе данных и конфиденциальности.

## 7. Интеграции

1. **Calendly** — inline-виджет на `/contact` (и кнопки-ссылки на других
   страницах). Нужна ссылка на аккаунт Calendly коуча.
2. **Контактная форма** — Formspree (или Netlify Forms): отправка на почту
   коуча, honeypot/anti-spam, страница «спасибо».
3. **Аналитика** (опц.) — Plausible / простой счётчик, без агрессивных трекеров
   в духе «low-noise».

---

## 8. SEO и технические детали

- Уникальные `title`/`description` и OpenGraph для каждой страницы.
- `sitemap.xml`, `robots.txt`, favicon, веб-манифест.
- Schema.org разметка (`ProfessionalService` / `Person`).
- Оптимизация изображений (Astro `<Image>`, WebP), Lighthouse 90+.
- Адаптивность: mobile-first, проверка на 360 / 768 / 1280 px.
